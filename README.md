
# 📦 Order System API

API robusta desarrollada con **Java 21** y **Spring Boot** para la gestión eficiente de pedidos y clientes, diseñada bajo una arquitectura limpia y persistencia en **PostgreSQL**.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Java 21
* **Framework:** Spring Boot 3.x
* **Base de Datos:** PostgreSQL 16 (vía Docker)
* **Documentación:** Swagger / OpenAPI 3
* **Herramientas:** Maven, Hibernate, Docker Compose

## 🚀 Configuración y Ejecución

### 1. Requisitos Previos
Tener instalado Docker y Java 21 en tu sistema.

### 2. Levantar la Infraestructura (Docker)
Desde la raíz del proyecto, ejecuta:
```bash
docker compose up -d
